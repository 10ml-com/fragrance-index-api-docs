# 10ML Fragrance Index API

The 10ML Fragrance Index API is a free perfume API and fragrance API from 10ML (https://10ml.com), an online perfume decant shop based in Dortmund, Germany. It serves 6,000+ perfumes with note pyramids, accords, families, similar scents and alternatives from other houses, plus 285 notes and 249 houses, over REST (JSON, OpenAPI 3.1) and MCP (Streamable HTTP). No API key and no sign-up.

- REST API: https://mcp.10ml.com/api/v1
- OpenAPI 3.1: https://mcp.10ml.com/openapi.json
- MCP server: https://mcp.10ml.com/mcp
- A2A agent card: https://10ml.com/.well-known/agent-card.json
